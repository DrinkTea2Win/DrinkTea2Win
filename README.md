# Shadow Rift

Оригинальная 2D action-RPG, вдохновлённая общими механиками dungeon crawler/idle RPG, без копирования персонажей, названий или ассетов чужих игр.

## Механики
- ручное движение и атаки;
- Auto-Battle/Auto-Tap после добровольного rewarded ad;
- 10 минут Auto-Battle после события `rewardEarned`;
- уровни, XP, золото и растущая сложность;
- элитные враги и этажи;
- выбор временных перков;
- три боевых стиля;
- AFK-лагерь;
- сохранение в localStorage;
- мобильное управление касанием и клавиатура.

## Rewarded Ads
Игра вызывает `AndroidAPI.showRewardedAd()` и выдаёт бонус только после события `rewardEarned`. Если API отсутствует, браузер не выдаёт игровой бонус.

## Запуск
Открой `index.html` или опубликуй репозиторий через GitHub Pages.
